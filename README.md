# Instapro

MVP социальной сети для обмена фотографиями

Удалось реализовать:
1. Авторизацию и регистрацию
2. Загрузку фото на страницу
3. Структуру приложения
4. Интеграцию верстки списков постов с АPI
5. Страницу добавления постов
6. Страницу с постами отдельного пользователя
7. Функционал лайков

## Первоначальная оценка

12 часов

## Фактически затраченное время

24 часов
